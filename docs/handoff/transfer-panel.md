# 핸드오프: 오른쪽 아래 전송 패널, 간결한 활동 기록

R1에서 리드가 정한 내용(P1~P6)과 그 세부의 기록. R2(테스트 코드 작성)·구현의 유일한 입력이다.
이 문서에 없는 케이스는 완료 범위 밖이다. 새 케이스를 추가하거나 기존 케이스를 재해석하지 말 것.

작업 유형(R0): **기능(UI) 1건 + 기존 UI 변경 2건**. 렌더러만 바꾼다. main·IPC·preload는 바꾸지 않는다. 스토어(`useTransferStore`)에는 패널 조각(`panel`·`panelMuted`·`panelHeld`·`panelSending`·`closePanel`·`togglePanelCollapsed`, P2)만 더한다.

- A. 새 `TransferPanel`: Google Drive처럼 창 오른쪽 아래에 뜨는 전송 진행 패널.
- B. 활동 팝오버(`ActivityPopover`)를 배치당 한 줄의 간결한 기록으로 바꾼다.
- C. 이 브랜치가 더한 "끌어 놓으면 카드가 활동 알약으로 날아가는" 신호(`dnd-upload-progress.md` D6)를 뺀다. 패널이 대신한다.

> 사용자 피드백: "아, 진행바를 오른쪽 위로 옮겼구나… 구글 드라이브처럼 오른쪽 아래에 팝업되는 형태로 구현할 수 있을까? 기존 활동 탭은 업로드/다운로드 기록을 더 간결하게 보여주게 바꾸면 좋을 것 같아."

---

## 1. 지금 동작

- 전송 진행은 툴바(오른쪽 위)의 활동 알약(`ActivityPill`)과, 그것을 눌러 여는 활동 팝오버에만 있다.
  팝오버는 배치마다 큰 카드(아이콘 32px, 진행 막대, 바이트·속도·남은 시간 줄, 실패 사유)를 그려 기록을 훑기 어렵다.
- 보내기가 시작돼도 아무것도 저절로 열리지 않는다. 끌어 놓기만 카드가 알약으로 날아간다(D6, Test-1100).
- 메뉴·선반·다운로드는 아무 신호 없이 알약 고리만 돈다.

## 6. R3 결과 (2026-10-13, macOS, dev 앱, 어두운 테마)

로컬 pyftpdlib 서버(127.0.0.1:2121, 2MB/s 제한)에 19MB 파일을 우클릭 "보내기"로 올렸다.

- 보내기를 고르자 오른쪽 아래에 패널이 펼친 채 떴다: 충돌 시트가 묻는 동안 "항목 1개 준비 중", 확인 뒤
  "항목 1개 업로드 중" + 전체 막대 + 행 막대 "58% · 4초 남음", 끝나면 "전송 1건 완료"와 체크 아이콘.
- 접기 단추는 머리만 남기고, 닫기 단추는 패널을 없앴다. 닫은 뒤 새 보내기는 펼친 새 패널에 그 행만 보였다.
- 활동 팝오버는 한 줄 기록 "✓ movie.bin → anonymous@127.0.0.1:21… 19.1MB · 오전 2:27"으로 보였다.
- 확인하지 못한 것: 밝은 테마, 긴 이름·de 로캘에서 팝오버 한 줄이 넘치는지. Finder에서 끌어 놓기는
  합성 입력이 HTML5 끌어 놓기를 일으키지 못해 손으로 확인해야 한다(경로는 `Explorer.test.tsx`가 실제
  Explorer로 고정).

## 7. multi-connection 위로 옮기며 바뀐 것 (2026-10-13)

PR #2(multi-connection·split view)가 main에 먼저 들어가 이 PR을 그 위로 다시 쌓았다.

- `send(conn, request, meta)`: 첫 인자가 원격 쪽 연결 키다. 준비 행 → 배치 바꾸기(P2a)는 그대로다.
  `batchKey`는 `batchId ?? job:<id>` 그대로 둔다: main의 `batchId`·작업 id가 모두 전역 UUID(`randomUUID`,
  `TransferQueue`·`RelayLane`)라 두 연결 사이에서 겹치지 않는다.
- 서버 간 복사(`relay`): 패널 요약은 `transferring`(P1b), `BatchIcon`은 도는 동안 relay 그림과 이름(P1d).
- multi-connection Test-1027의 팝오버 단언 중 "받는 쪽 바이트 `1000 B / 7.8 KB` 글자"는 압축 기록(P4b)이
  도는 묶음에 바이트 대신 퍼센트를 보이므로, 같은 받는 쪽 바이트로 계산한 행 막대의 `aria-valuenow`(13)로 바꿨다.
